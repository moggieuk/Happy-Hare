# Happy Hare v3 resources

Happy Hare v3 remains available on the [`v3` branch](https://github.com/moggieuk/Happy-Hare/tree/v3)
for existing installations that are not yet ready to move to v4.

The [Happy Hare v3 wiki](https://github.com/moggieuk/Happy-Hare/wiki) is the
complete reference for v3 installation, configuration, calibration, operation,
troubleshooting and feature setup. Because v3 and v4 use different module and
configuration layouts, use the wiki for v3 systems and the new documentation
site for v4 systems.

## Community and support

- Join the [Happy Hare Discord](https://discord.gg/aABQUjkZPk) for setup help and
  discussion with other v3 users.
- Use the [GitHub issue tracker](https://github.com/moggieuk/Happy-Hare/issues)
  for reproducible bugs and feature requests.
- If you decide to migrate, read the
  [v3-to-v4 upgrade guide](https://moggieuk.github.io/Happy-Hare-Doc/Upgrade-v3-v4/)
  before changing branches.
